# Mobile release checklist

## Completed in the repository

- [x] Expo SDK 57 native app scaffold
- [x] iOS bundle ID and Android package: `com.saylorinnovations.propz`
- [x] Local jar persistence, validation, QR, copy, share, and hosted-flow link
- [x] Non-custodial and fee disclosures
- [x] Branded iOS/legacy Android icon, Android adaptive icon, monochrome icon, favicon, and splash artwork
- [x] Dedicated mobile privacy policy source
- [x] Store copy, reviewer notes, privacy worksheet, and screenshot plan

## Account-owner gates

- [ ] Confirm whether Saylor Innovations already has a D-U-N-S number; request one if not.
- [ ] Enroll Saylor Innovations as an Apple Developer Program organization and pay Apple’s current annual fee.
- [ ] Create/verify a Google Play Console organization account and pay Google’s current registration fee.
- [ ] Create or sign in to an Expo/EAS account.
- [ ] Accept Apple and Google legal agreements and complete identity/business verification.
- [ ] Confirm company legal name, address, phone, support email, tax profile, and public developer contact details.

## Build and QA

- [ ] Add the EAS project ID generated by `eas init` to app config.
- [ ] Run `npx eas-cli@latest build --platform all --profile preview` while signed in.
- [ ] Install preview builds on at least one current iPhone/iPad and Android phone.
- [ ] Verify cold launch, keyboard behavior, validation, local save/restore, QR scan, copy, share, hosted flow, offline/error behavior, Dynamic Type/font scaling, VoiceOver/TalkBack labels, and dark appearance.
- [ ] Confirm the recipient receives the chosen tip amount and the 1% fee is added separately on both supported networks.
- [ ] Capture final screenshots from preview or production builds.
- [ ] Run `npm run typecheck`, `npm run doctor`, and `npx expo config --type public` immediately before building.

## Store submission

- [ ] Create App Store Connect app record and Play Console app record.
- [ ] Paste metadata from `STORE_LISTING.md` and upload final screenshots/assets.
- [ ] Publish `https://propz.saylorinnovations.com/mobile-privacy` from the release branch and confirm HTTP 200 before submission.
- [ ] Complete Apple App Privacy and Google Data safety using `PRIVACY_DECLARATIONS.md`, updated for the exact production binary.
- [ ] Complete Google’s Financial features declaration conservatively.
- [ ] Paste `REVIEW_NOTES.md` into reviewer notes and include a company-controlled public test address.
- [ ] Choose initial country availability only after confirming crypto-transfer legality and wallet availability for those storefronts.
- [ ] Obtain legal/policy approval for the iOS fee interpretation documented in `REVIEW_NOTES.md`.
- [ ] Build production binaries, submit, monitor review messages, and answer reviewers without changing the product description.
