Set up your tip jar

This is what shows up when you enable Propz on a page.

Enter a valid Solana public address.

Enter a valid 0x public address.

Public receiving address only — never a seed phrase or private key. Propz never asks for one and can't hold funds either way.

Add at least one valid Solana or Base address.

0.08% platform fee on every tip, disclosed to supporters before they send — the rest goes straight to you.

You're set up

Now go to any page you want your tip button on.

Click the Propz icon in your toolbar, then "Show on this page." It'll appear there for every visitor — not just you — including on pages you can't add a script to, like a GoFundMe campaign.

You can change this anytime from the toolbar popup.
